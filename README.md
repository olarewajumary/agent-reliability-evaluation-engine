
# Agent Reliability & Evaluation Engine

An engineering project focused on evaluating the reliability of
multi-step, tool-using AI agents.

## Problem

AI agents can select incorrect tools, execute actions in the wrong
order, retrieve irrelevant information, violate permissions, or
produce answers unsupported by available evidence.

A successful response does not necessarily mean the agent completed
the task correctly or safely.

## Project Goal

Build an evaluation system that measures how reliably an AI agent
performs tasks involving multiple tools and decision-making steps.

## Planned Capabilities

- Tool selection and execution evaluation
- Retrieval quality assessment
- Execution trace collection
- Permission and approval checks
- Answer grounding and correctness evaluation
- Failure analysis
- Performance monitoring

## Technology Stack

- Python
- FastAPI
- Pydantic
- Pytest
- SQLite
- HTTPX
